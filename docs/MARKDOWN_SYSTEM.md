# Documentation structure

Use `docs/MARKDOWN_INDEX.md` to find product and research documentation.
Public experiment artifacts live in `experiments-local/`, with a run index in
`experiments-local/registry/INDEX.md`. Historical results and interpretations
are recorded in `docs/research/R_AND_D_LEDGER.md`.

When adding research evidence, include reproducible commands, configuration,
limitations, and the relationship to earlier results. Preserve scientific
caveats and distinguish proposals from completed measurements.

The index and registry are documentation aids, not an execution queue. Local
coordination notes and account or machine state belong outside this repository.
