# Research contribution checklist

Before submitting an evaluation change:

- Record the dataset, model/configuration, commands, and output paths.
- Preserve unfavorable results and distinguish measured results from interpretation.
- Add new public experiment artifacts to `experiments-local/registry/INDEX.md`.
- Link new reports from `docs/MARKDOWN_INDEX.md`.
- State limitations and incomplete runs explicitly.
- Run `scripts/check_research_hygiene.sh` to check indexed file references.

Keep account details, machine paths, and session notes outside the repository.
