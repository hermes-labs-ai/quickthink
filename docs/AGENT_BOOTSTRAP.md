# Contributor starting points

Read `README.md` for installation and supported behavior, `AGENTS.md` for
contribution commands and invariants, and `FOLDER_MAP.md` for the source layout.
`docs/MARKDOWN_INDEX.md` indexes the public documentation.

For evaluation work, use `docs/evals/AGENT_HANDOFF.md` and the canonical
`scripts/eval_harness/` pipeline. Historical experiments are indexed in
`experiments-local/registry/INDEX.md`; they are evidence with the limitations
recorded for each run, not instructions to resume old work.
